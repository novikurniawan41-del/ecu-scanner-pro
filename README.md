# ECU SCANNER PRO

Aplikasi web diagnostik OBD-II (ELM327) dengan Live Data, DTC, Freeze Frame, I/M Readiness, laporan, dan Demo Mode (SIMULASI).

## Deploy di GitHub Pages
1. Buat repository baru, unggah `index.html` dan `README.md` ke branch `main`.
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
3. Buka `https://USERNAME.github.io/NAMA-REPO/` di Chrome (HTTPS wajib untuk Bluetooth/USB).

## Catatan
- Bluetooth LE: Chrome Android/desktop. USB/Serial: Chrome desktop.
- Adapter Bluetooth Classic tidak didukung browser.
- Tidak ada data yang dikirim ke server; penyimpanan lokal hanya dengan izin pengguna.
